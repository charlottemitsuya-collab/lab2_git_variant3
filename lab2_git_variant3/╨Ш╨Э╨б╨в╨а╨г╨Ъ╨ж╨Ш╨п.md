# Порядок выполнения лабораторной №2, вариант 3

Откройте терминал VS Code в папке проекта. Убедитесь, что установлены Python и Git.

## 1. Создание локального репозитория и первого коммита

```bash
git init -b main
git add main.py README.md .gitignore
git commit -m "Initial commit: main application"
```

`weather.py` пока **не добавляйте** в первый коммит: он должен появиться в отдельной ветке.

## 2. Создание пустого репозитория на GitHub

На https://github.com нажмите New repository, назовите его `lab2_git_variant3`, выберите Public или Private и **не** включайте автоматическое создание README/.gitignore. Скопируйте HTTPS-адрес своего репозитория.

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/lab2_git_variant3.git
git push -u origin main
```

Вместо `ВАШ_ЛОГИН` укажите свой логин GitHub. При запросе авторизации войдите через Git Credential Manager или используйте поддерживаемый метод входа.

## 3. Новый коммит и повторный push в main

Измените текст сообщения в `main.py`, сохраните файл, затем выполните:

```bash
git add main.py
git commit -m "Update main application message"
git push
```

## 4. Создание и публикация feature

```bash
git switch -c feature
git add weather.py
git commit -m "Add weather information script"
git push -u origin feature
```

## 5. Pull Request

Откройте страницу репозитория на GitHub. Нажмите Compare & pull request рядом с веткой `feature` (или Pull requests → New pull request). Выберите `base: main`, `compare: feature`, введите название `Add weather information script`, создайте PR. При необходимости нажмите Merge pull request и Confirm merge. Если преподавателю нужно показать открытый PR, не сливайте его до проверки.

## 6. Проверка clone и pull во втором каталоге

Перейдите из папки проекта на уровень выше, затем:

```bash
git clone https://github.com/ВАШ_ЛОГИН/lab2_git_variant3.git lab2_clone
cd lab2_clone
python main.py
```

Если PR уже слит, в клоне можно запустить и `python weather.py`.

Чтобы проверить `pull`, в исходном проекте переключитесь на `main`, измените `main.py`, выполните commit и push. Потом в папке `lab2_clone` выполните:

```bash
git pull origin main
```

Если Pull Request ещё не слит, `weather.py` доступен в ветке feature, а не в main. Получить её можно командами `git fetch origin` и `git switch -c feature --track origin/feature`.

## 7. Что показать преподавателю

- Страницу GitHub с ветками `main` и `feature`.
- Историю коммитов; два push в `main` и один в `feature`.
- Pull Request `feature → main`.
- Терминал с `git remote -v`, `git branch -a`, `git log --oneline --all --graph`, `git pull origin main`.
- Работу `python main.py` и `python weather.py`.

## Важное замечание

GitHub-репозиторий, пуши и PR не создаются автоматически при скачивании архива. Их надо выполнить в вашем аккаунте по шагам выше. Папка проекта намеренно передаётся без `.git`, чтобы вы сами сформировали историю коммитов по заданию.
